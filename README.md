# DynaTech AI Chatbot

An educational AI chatbot built on Botpress Cloud that teaches users fundamental Artificial Intelligence concepts and assesses their understanding through multiple-choice quizzes.

## Features
- Teaches 8+ AI topics: Machine Learning, Deep Learning, NLP, Computer Vision, Neural Networks, AI Ethics, Prompt Engineering, Generative AI
- Interactive topic selection menu via quick-reply buttons
- Multiple-choice quiz with 3 difficulty levels (Beginner, Intermediate, Advanced)
- Automated closing acknowledgement and quiz recap
- Accessible via a shareable webchat link — no app download required

## Platform
Built with Botpress Cloud (Webchat v3.6)
